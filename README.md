# Counter-Strike-2-Vscript-Anticheat-universal
A lightweight server-side anti-cheat for CS2 written in VScript (JS). Monitors movement, combat events, and player statistics in real-time.Detection: Bhop ($>320\text{ u/s}$), Triggerbot ($&lt;0.08\text{s}$ kill delay), perfect HS %, wallbangs &amp; Wall-Look heuristics.Commands: !pac, !pacverif [name], !pacon/!pacoff.No external dependencies.
